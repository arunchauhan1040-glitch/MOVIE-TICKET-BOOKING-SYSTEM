# MOVIE-TICKET-BOOKING-SYSTEM

A modular, menu-driven C++ Movie Ticket Booking System developed for the TCS-504 System Design Assignment. Includes movie/show listing, seat availability, seat booking, tier-based pricing, UPI/Card/Cash payment, ticket generation, booking cancellation, OOP concepts, SOLID principles, validation, and edge-case handling.

## Features
- List currently playing movies
- List shows with screen and start time
- Display AVAILABLE / BOOKED seat status
- Book one or more seats
- Reject already-booked or invalid seats
- Tier-based pricing: SILVER ₹150, GOLD ₹250, PLATINUM ₹400
- UPI, Card, and Cash payment options
- Failed payment releases seats and does not confirm booking
- Generate and print ticket details
- Cancel confirmed bookings and release seats

## OOP & Design Concepts
Encapsulation, Abstraction, Inheritance, Runtime Polymorphism, Compile-Time Polymorphism, Static Members, `this` keyword, Composition, Aggregation, Association, and SOLID principles.

## Language
C++
